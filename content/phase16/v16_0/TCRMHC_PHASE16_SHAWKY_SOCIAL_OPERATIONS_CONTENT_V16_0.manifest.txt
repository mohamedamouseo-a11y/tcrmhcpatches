SOURCE_CONFIRMED_SCOPE:
- Shawky identifies as an AI Social Media Specialist inside TCRM.
- Shawky uses a Postiz runtime and exposes live runtime health, connected-account, post, and summary data.
- Dashboard metrics include connected accounts, scheduled posts, published posts, drafts, and engine state.
- The default UI range is the previous 30 days; backend date-range validation caps requests at 93 days.
- Content and Calendar consume live Postiz data and explicitly show unavailable/empty states instead of fabricated placeholder data.
- Social Accounts supports configured OAuth providers including Facebook, Instagram, LinkedIn, TikTok, X, and YouTube variants.
- Meta OAuth can require explicit account selection before completing the connection.
- The Content Composer supports text, account selection, media, Save Draft, Schedule, and Publish Now.
- Composer validation allows at most 5,000 text characters, 12 unique social account integrations, and 10 media items.
- Images support JPEG/PNG/GIF/WebP/AVIF/BMP/TIFF up to 10 MB; video is MP4 up to 1 GB.
- Media upload requires Admin authentication and same-origin requests, uses the server-side Postiz API key, and validates the returned HTTPS public media URL.
- Scheduling requires a valid future time.
- Immediate publishing is protected by an explicit confirmation gate.
- Publish confirmations expire after 10 minutes, are bound to the initiating user, and are consumed before the outbound publish request to reduce duplicate-post risk.
- Shawky router access is Admin-only.
- Postiz runtime URL is restricted to loopback hosts and Postiz credentials remain server-side.
- Analytics, AI, and Settings are currently pending workspaces and are not documented as completed live functionality.
